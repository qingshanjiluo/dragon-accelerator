📖 使用教程

  1. 启动加速器 — 运行 npm start，代理自动启动
  2. 配置浏览器代理 — 设置 → 网络 → 代理 → 手动代理：
    HTTP: 127.0.0.1 端口: 9527
    HTTPS: 127.0.0.1 端口: 9527
  3. 打开游戏 — 访问 https://game.mk49.top 或 https://mk48.io
  4. 首次加载 — 资源会从远程下载并缓存（约1-2秒）
  5. 后续加载 — 资源从本地缓存读取（<1ms），秒开！
  6. 查看仪表盘 — 浏览器打开 http://localhost:3949
  7. 自动操作 — 在「设置」页面开启自动瞄准/开火/规避/收集
  8. 多开账号 — 在「多开」页面添加账号，每个账号独立代理端口
  9. 保持登录 — 默认开启，每5分钟发送心跳保持连接

⚡ 加速原理

  1. 资源缓存 — JS/WASM/图片首次下载后存本地，后续直接读取
  2. DNS 预解析 — 启动时提前解析游戏域名，消除 DNS 延迟
  3. TCP 优化 — 连接池复用 + NoDelay 减少握手开销
  4. WebSocket 中继 — 游戏实时数据通过本地 WS 中继转发

🔧 代理配置详解

  1. Chrome: 设置 → 系统 → 打开代理设置 → 局域网设置 → 代理服务器
  2. Firefox: 设置 → 网络设置 → 手动代理配置
  3. 系统级: Windows 设置 → 网络 → 代理 → 手动设置

☁️ Cloudflare 部署

  1. 项目包含 cloudflare-worker.js 可部署到 Cloudflare Workers
  2. 运行 wrangler deploy 即可部署
  3. 通过 Worker URL 访问游戏，自带 CDN 加速
